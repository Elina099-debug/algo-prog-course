## ПР1. Ответы на контрольные вопросы

**1.** В C# ошибки находятся при компиляции, до запуска. В Python только когда выполнение дойдёт до кривой строки.

**2.** Сначала собирает проект, потом запускает его.

**3.** Это папки с результатами сборки. Они создаются автоматически, поэтому в Git их не кладут, только лишний мусор.

**4.** commit сохраняет изменения у меня на компьютере, push отправляет их на GitHub.

**5.** + склеивает строки по кусочкам, $"..." вставляет переменные прямо в текст через {}. Интерполяция удобнее и читается проще.

**6.** Получится целое число, дробь отбросится: 25 / 4 будет 6. Чтобы вышло 6,25, пишем 25.0 / 4 или (double)25 / 4.

**7.** const нельзя менять после объявления, обычную переменную можно. Например, const double VatRate = 0.20;.

**8.** Это код прямо в Program.cs без класса Program и метода Main, их создаёт компилятор. Работает так же, просто короче.
